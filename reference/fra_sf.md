# Map of France

A map of France as sf object. Can be used as dataset or for maps

## Usage

``` r
fra_sf
```

## Format

A data frame with 96 rows, 5 variables and a spatial geometry
(MULTIPOLYGON):

- OBJECTID:

  polygon identifier

- pays:

  country: France

- region:

  region name

- departement:

  departement name

- id_dpt:

  departement id

- geometry:

  polygon geometry
